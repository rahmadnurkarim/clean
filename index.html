PANDUAN IMPOR DATA RESMI INSTAGRAM
1. Buka Instagram → Accounts Center / Pusat Akun.
2. Pilih Your information and permissions → Download your information.
3. Pilih akun Instagram, lalu pilih Followers and following (serta data profil bila diperlukan).
4. Pilih format JSON dan rentang waktu yang diinginkan, lalu minta unduhan.
5. Setelah arsip tersedia, ekstrak file JSON dan impor ke InstaClean melalui tombol Impor JSON.

InstaClean tidak mengakses endpoint internal, cookie, sesi login, atau melakukan scraping otomatis.
Pemindaian real-time melalui endpoint privat tidak disediakan. Data yang tidak ada di file sumber tidak akan direka.
