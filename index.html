InstaClean Unified Scanner

Impor arsip resmi Instagram untuk menggabungkan Followers dan Following, menghitung relasi akun, lalu menyimpan seluruh workspace sebagai instaclean_data.json.

1. Dual ScannerMembaca seluruh bagian Followers dan Following, termasuk followers_1.json dan seterusnya.
2. Profile SyncMempertahankan informasi profil/metadata jika tersedia dalam file yang diimpor.
3. Single JSONEkspor akun, relasi, whitelist, metadata, dan ringkasan dalam satu file.
IMPOR ARSIP RESMI INSTAGRAM
  1. Buka Instagram → Pusat Akun (Accounts Center).
  2. Pilih Informasi dan izin Anda → Unduh informasi Anda.
  3. Pilih akun Instagram dan kategori Followers and following. Sertakan informasi profil bila diperlukan.
  4. Pilih format JSON, rentang waktu yang diinginkan, lalu buat unduhan.
  5. Ekstrak ZIP. Pilih semua file JSON Followers dan file Following yang relevan di bawah ini.

Belum ada arsip yang diimpor. Anda dapat memilih beberapa file sekaligus.

Pemrosesan dilakukan lokal di browser. Aplikasi tidak meminta kata sandi, membaca cookie/sesi, mengakses endpoint privat, atau melakukan unfollow otomatis. Metrik profil yang tidak tersedia dalam arsip akan dibiarkan kosong.
